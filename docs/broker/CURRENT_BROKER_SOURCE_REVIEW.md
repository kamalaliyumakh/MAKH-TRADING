## Source-control rules

- Re-open each official source at the time of selection, contracting and certification.
- Record entity names, regulator identifiers, status/function, review date and source evidence.
- Candidate marketing, API documentation and sandbox access cannot substitute regulatory, eligibility or contract evidence.
- Third-party comparisons and Codex analysis cannot establish provider eligibility or suitability.
