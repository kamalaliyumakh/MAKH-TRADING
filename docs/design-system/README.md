# MAKH Trading Platform — Design System Baseline

Last updated: 12 August 2026  
Status: Approved baseline for WBS 2.5

## Contents

- `BRAND_DIRECTION.md` — product personality, voice, visual principles and usage boundaries.
- `tokens.json` — platform-neutral design-token source.
- `tokens.css` — generated-compatible CSS custom-property baseline for Angular.
- `COMPONENT_CATALOGUE.md` — reusable public, portal, data and trading components.
- `RESPONSIVE_AND_STATES.md` — breakpoints, layout behavior and complete UI state model.
- `ANGULAR_IMPLEMENTATION.md` — `libs/ui` architecture, accessibility and verification rules.

The system is deliberately calm and evidence-led. It avoids visual patterns associated with gambling, urgency or guaranteed performance. WBS 2.6 and 2.7 will apply these foundations to the landing and portal prototypes.
