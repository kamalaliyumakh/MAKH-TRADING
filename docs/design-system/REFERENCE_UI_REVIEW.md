# MAKH Trading — Reference UI Review

Date: 20 August 2026  
Status: Implemented visual direction; human acceptance pending

## Adopted characteristics

- Near-black navy application canvas with layered blue-grey cards and fine borders.
- Orange brand/interaction accent, white display typography and green positive/healthy metrics.
- Public hero with large value proposition, synthetic market chart and immediate risk boundary.
- Dense authenticated workstation with fixed desktop rail, KPI cards, tables, charts and explicit state badges.
- Responsive single-column content and contained navigation/table scrolling.
- Supplied MAKH artwork used as the source mark, paired with an accessible HTML wordmark for dark-background contrast.

## Changes applied

- Updated both Angular application token layers and global surfaces.
- Rebuilt the portal shell from a wrapping header into a 15rem desktop rail with mobile fallback.
- Updated public header, CTA, cards, forms, footer and hero atmosphere.
- Preserved existing accessible chart titles/descriptions, skip links, landmarks and responsive behavior.

## Deliberately excluded from the references

- Live order entry, live balances, live portfolio claims and broker authority.
- Active kill switch, provider configuration mutation, alert creation and account/profile mutation.
- Performance promises or treating green/upward imagery as a recommendation.

These controls require their existing identity, risk, broker, reconciliation, privacy and accountable-approval gates. Their appearance in a design reference does not grant implementation or operational authority.
