## Decision rules

- Every decision binds one provider entity, account, region/zone, service/tier/version, topology, data-flow map, configuration, quote and evidence manifest.
- Any provider, region, tier, topology, account, data class, RPO/RTO, terms or price change requires a new decision.
- Local containers, infrastructure templates, a calculator estimate or provider documentation cannot substitute deployed managed-service evidence.
- Codex may prepare comparisons and verify evidence structure. Codex cannot select/contact a provider, accept terms, create an account, subscribe, provision, create secrets, enable connectivity, incur spend, deploy workloads or authorize paper/live production.
