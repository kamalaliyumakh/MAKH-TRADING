# MAKH Trading Platform — Hosting Evaluation

WBS 1.5 evidence package. It defines the hosting requirements, compares managed-cloud options, models cost without inventing quotes, sets recovery/operations acceptance tests, and records a proposed architecture decision.

- `HOSTING_REQUIREMENTS.md` — mandatory service and operating requirements.
- `HOSTING_COMPARISON.md` — Azure, AWS and Google Cloud assessment.
- `COST_AND_CAPACITY_MODEL.md` — environments, sizing variables and quote template.
- `RECOVERY_AND_OPERATIONS_ACCEPTANCE.md` — evidence required before production acceptance.
- `../architecture/adr/ADR-0005-AZURE-MANAGED-CONTAINER-PLATFORM.md` — proposed, not accepted, hosting decision.
- `../../outputs/hosting-discovery-readiness/readiness-manifest.json` — executable inventory, hashes, blockers and no-authority result.

No cloud account, subscription, resource, secret or paid service has been created by this package.
