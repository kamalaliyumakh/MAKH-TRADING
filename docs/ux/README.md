# MAKH Trading Platform — UX Discovery Baseline

Last updated: 12 August 2026  
WBS evidence: 1.6 — landing page, portal workflows and accessibility research

## Contents

- `UX_RESEARCH_FINDINGS.md` — requirements-derived findings, needs, risks and design implications.
- `PERSONAS_AND_JOURNEYS.md` — provisional user archetypes and critical end-to-end journeys.
- `INFORMATION_ARCHITECTURE.md` — public and authenticated navigation/content model.
- `ACCESSIBILITY_BASELINE.md` — WCAG 2.2 AA-targeted interaction and verification requirements.
- `VALIDATION_PLAN.md` — assumptions and primary research still required before UX approval.

This baseline synthesizes the approved BRD/PRD, FSD, architecture, security, data and API work. It is not a claim that interviews or usability tests have already occurred. Provisional findings are sufficient to begin the design system; final copy and high-risk workflows still require representative-user, legal and accessibility validation.
